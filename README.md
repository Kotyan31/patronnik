# Патронник

Buckshot Roulette, но это математика. Каждый патрон — формула: продолжите график за линию спуска.
Вниз — боевой, вверх — холостой. Музыка и формулы генерируются заново в каждой игре.

Играть: https://kotyan31.github.io/patronnik/

## Таблица рекордов

Игрок один раз вводит ник и пароль. Из них в браузере получается ключ подписи (PBKDF2 → P-256),
сам пароль никуда не уходит. После каждой игры результат подписывается и сам уходит комментарием
в закрытую заявку `patronnik-scores`. Workflow `.github/workflows/scores.yml` (скрипт `.github/lb.py`)
проверяет подпись: первый результат закрепляет ник за ключом, следующие должны быть подписаны тем же
ключом. Потом пишет `scores.json` и удаляет комментарий.

Настройка (один раз):
1. Создать fine-grained токен только для этого репозитория с правом Issues: Read and write.
2. Положить его в секрет репозитория `LB_PAT` (Settings → Secrets and variables → Actions).
3. Запустить workflow `scores` вручную (Actions → scores → Run workflow): он создаст заявку и `lb.json`.

Токен попадает в `lb.json` и виден в коде страницы — так и задумано: с ним можно работать только
с заявками (issues) этого репозитория, код и файлы он не трогает.
