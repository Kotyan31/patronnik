# Патронник

Buckshot Roulette, но это математика. Каждый патрон — формула: продолжите график за линию спуска.
Вниз — боевой, вверх — холостой. Музыка и формулы генерируются заново в каждой игре.

Играть: https://kotyan31.github.io/patronnik/

Общая таблица рекордов — `scores.json`. Результат отправляется из игры заявкой (issue),
workflow `.github/workflows/scores.yml` проверяет его и записывает в таблицу.
